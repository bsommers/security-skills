# Security Policy

## Supported versions

Only the latest release (and the current `main` branch) receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's private vulnerability reporting:
open the repository's **Security** tab, choose **Report a vulnerability** (Security Advisories), and describe the issue with reproduction steps. Do not open a public issue for security problems.

## Response expectations

- Acknowledgement within about 7 days.
- Initial assessment within about 14 days.
- Fixes are released as soon as practical, with credit to the reporter if desired. This is a volunteer-maintained project; timelines are best effort.

## Scope

These skills are instruction files (and a small installer script) that run locally inside your AI coding agent, with the permissions you grant it. CVE database downloads come from public sources (OSV and NVD); this project does not operate those services. Vulnerabilities in OSV/NVD data, Claude Code, or third-party tools should be reported to their respective maintainers.
